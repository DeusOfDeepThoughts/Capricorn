# ♑ Capricorn

## 💖 作者：超爱你的派大星

> 把一个真正有性格、记得住你的人，放到桌面上。

Capricorn 是一款 Windows AI 桌宠应用。它会安静地待在桌面一角，陪你聊天、记住重要的事，也会用属于自己的性格回应你。

你可以创造温柔的倾听者、冷静的分析派、活泼的开心果，或者一个只属于你的老朋友。它们不只是换了名字和头像：**每只桌宠都有独立的人格、关系和共同回忆。**

🐾 **会动的桌宠**　·　💬 **有性格的对话**　·　🧠 **能延续的记忆**　·　🧬 **由你创造的人格**

---

## 🌟 你为什么可能会喜欢 Capricorn

### 💬 想找个人说说话时，它就在桌面上

聊工作、聊爱好、吐槽今天，或者只说一句“有点累”都可以。不必每次都写一份格式完整的问题，也不必面对千篇一律的“您好，请问有什么可以帮您”。

### 🧠 有些事，不用每次重新解释

Capricorn 会整理你明确说过的偏好、目标、近况和重要经历。下一次聊天时，它可以在已有上下文上继续，而不是从“你好”重新认识你。

### 🧬 你决定它是什么样的

你可以决定桌宠怎样思考、怎样表达、在意什么，以及和你保持怎样的距离。人格强度可以调节：从温和克制，到个性鲜明，都由你掌舵。

### 🐾 不止一位桌面搭子，也不会莫名串台

你可以创建多只桌宠。它们会共享必要的用户信息，但各自保留与你的专属关系：称呼、约定、共同经历和小摩擦，都属于对应的那一位。

## ✨ 主要能力

- **动态桌宠**：透明悬浮、拖动、置顶、锁定位置、隐藏和关闭
- **个性化对话**：回答风格受人格设定和人格强度影响
- **连续记忆**：分开管理用户记忆、关系记忆和结构化事实
- **人格创作**：通过回答问题创建人格，不需要会写提示词
- **用户画像**：整理常聊话题、关键词、近期关注点和互动概况
- **语音输入**：接入百度实时语音识别，将中文普通话实时转成文字
- **聊天管理**：选择、批量删除、导入和导出聊天记录
- **人格分享**：将人格导出为 `.petpack` 或 ZIP，也可以导入他人分享的人格包

## 🚀 第一次使用：五步召唤桌宠

不需要编程，也不需要自己部署服务器。准备好一个兼容的大模型 API 后：

1. 安装并打开 Capricorn。
2. 选择内置人格，或进入 **编辑人格** 创建一个新人格。
3. 在 **构建宠物** 页面填写模型服务信息。
4. 点击 **保存**，完成模型连接验证。
5. 点击 **生成桌宠**，和它说第一句话。

> 💡 API 可以理解为桌宠连接 AI 服务的“通行证”。Capricorn 不附赠模型账号或额度，需要使用你自己的服务配置。

## 🧭 新手配置指南：照着做就能用

下面是派大星调试 Capricorn 时采用的快速入门方案，适合第一次接触模型 API 的朋友。它不是唯一方案，你也可以配置其他兼容服务。

### 1. 模型服务：使用 DeepRouter 快速入门

> 熟悉模型服务的朋友可以直接跳过；第一次配置的朋友按顺序填写即可。

1. 打开 [DeepRouter](https://www.deeprouter.top/)，注册账号并充值 5 元。
2. 在 Capricorn 的 **构建宠物** 页面填写：
   - **Base URL**：`https://www.deeprouter.top/v1`
   - **模型 ID**：`gpt-5.6-luna`
3. 回到 DeepRouter 控制台，进入 **API 密钥 → 创建 API 密钥**。
4. 输入密钥名称，点击 **保存更改**。
5. 复制生成的 API 密钥，粘贴到 Capricorn 的 **API 密钥** 框。
6. 点击 Capricorn 中的 **保存**，然后进行模型连接验证。

### 2. 实时语音：配置百度语音识别

> 语音输入是可选功能。不想说话时，跳过本节也完全不影响文字聊天。

1. 打开 [百度智能云语音服务](https://console.bce.baidu.com/ai-engine/speech/overview/index)，完成页面顶部的 **STEP 1** 和 **STEP 2**。按当前页面规则，通常可获得 10 小时免费额度，日常使用基本够用。
2. **完成 STEP 1：个人认证**
   - 点击用户头像 → **账号管理** → **个人认证**。
   - 选择 **个人刷脸认证**，按页面提示完成认证。
3. **完成 STEP 2：创建语音应用**
   - 应用名称和应用描述可随意填写。
   - 语音技术只选择 **实时语音识别**。
   - 点击 **立即创建**。
4. 打开 [百度语音应用列表](https://console.bce.baidu.com/ai-engine/speech/app/list)。
5. 找到刚刚创建的应用；如果列表中没有，也可以点击 **创建应用**，仅选择 **实时语音识别** 后创建。
6. 复制应用的 **APP ID**，粘贴到 Capricorn 的百度实时语音识别配置中的 **APP ID** 框。
7. 复制 **API Key**，粘贴到 Capricorn 的 **API Key** 框。
8. 点击 **保存**，回到聊天页面即可尝试语音输入。

### 3. 桌宠形象：制作客制化 SVG 动作包

> 想让喜欢的角色住进桌面？下面是一条适合新手的快速路线。熟悉 SVG、矢量绘图或动画设计的朋友，可以直接自由发挥。

1. **准备角色原图**
   - 下载或绘制一张喜欢的角色图片。
   - 尽量选择主体完整、轮廓清晰、分辨率较高的图片，后续处理会轻松很多。
2. **抠除背景**
   - 使用在线美图秀秀等图片工具进行抠图。
   - 检查头发、衣角和饰品边缘，确保背景已经透明，避免桌宠身后跟着一块“祖传白底”。
3. **提升清晰度**
   - 在在线美图秀秀中使用 **变清晰 → AI 超清**，提高角色细节和边缘质量。
4. **导出 PNG 原图**
   - 下载时选择 **PNG** 格式，以保留透明背景。
5. **生成 SVG 姿态图**
   - 将 PNG 原图交给 ChatGPT、豆包、Kimi 或其他支持图片处理/代码生成的 AI。
   - 请 AI 以原图为角色参考，生成 **1～10 张 SVG 姿态图**。
   - 建议让不同姿态包含小幅运动和丰富的动作或表情，例如呼吸、眨眼、挥手、开心、惊讶、思考和说话。
   - 要求各张 SVG 保持角色画风、比例、配色和画布尺寸一致，并使用透明背景。
6. **整理并导入动作包**
   - 将生成的所有 `.svg` 文件放进同一个文件夹。
   - 把文件夹压缩为 ZIP 或 RAR。
   - 打开 Capricorn 的 **编辑人格** 页面，在 **桌宠形象** 中载入压缩包。
   - 保存人格并重新生成桌宠，即可查看客制化形象。

> 💡 如果动作差异过大，桌宠切换姿态时可能像瞬移；尽量保持角色位置、大小和朝向一致，只改变表情与小幅动作，效果通常更自然。

> 📌 DeepRouter、百度智能云、美图秀秀以及文中提到的 AI 工具，只是帮助新用户快速生成第一只 AI 桌宠的示例方案。项目与这些服务不存在利益关系；你完全可以选择其他兼容服务和工具，并承担对应的费用、版权与服务条款责任。制作和分享桌宠形象时，请确保你有权使用相关图片与角色素材。

## 🔌 模型服务支持

Capricorn 不绑定某一家模型厂商，可连接以下兼容接口：

- OpenAI Chat Completions
- OpenAI Responses
- Anthropic Messages
- 其他提供兼容接口的模型服务

你可以填写自定义服务地址、模型 ID 和 API Key。换句话说，你决定桌宠使用哪颗“大脑”。

> ⚠️ AI 对话需要联网，聊天内容会发送到你选择的模型服务商。模型没有被完整下载到本地，也没有藏在桌宠 SVG 里。

## 🧰 日常使用指南

### 🧬 创建或修改人格

1. 打开 **编辑人格**，回答核心问题和延伸问题。
2. 填写人格名称，选择喜欢的桌宠形象。
3. 调整人格强度并保存。
4. 进入 **人格管理**，点击 **使用**。
5. 在 **构建宠物** 页面完成模型配置并点击 **生成桌宠**。

修改正在使用的人格后，通常需要先关闭当前桌宠，再重新点击 **使用**，让最新配置生效。

### 🐾 管理桌宠

在桌宠上点击右键，可以使用聊天、置顶、固定当前位置、隐藏桌宠、导入/导出聊天记录和关闭桌宠等功能。

### 💬 管理聊天记录

在聊天窗口中可以选择消息、全选消息和批量删除，也可以从桌宠菜单导入或导出当前聊天记录。删除前请确认范围；删掉的内容不会神奇地从云端变出备份。

### 📦 分享人格

进入 **人格管理 → 导出人格**，选择需要分享的模块后导出 `.petpack` 或 ZIP。导出包可能包含你的回答、偏好和敏感信息，分享前请检查内容。

## 🔐 数据、隐私与费用说明

- 人格、配置、聊天记录和长期记忆保存在本机用户 AppData
- 聊天和记忆使用本地 SQLite 持久化
- 安装、覆盖升级和普通卸载默认保留用户数据
- 模型请求会发送到你配置的第三方模型服务
- 启用语音输入后，语音内容会发送到百度实时语音服务
- 人格包可能包含你的回答，分享前请检查导出模块
- DeepRouter、百度智能云等第三方服务的费用、额度、认证和服务规则以其官方页面为准

使用第三方服务前，请阅读对应服务商的隐私政策和数据处理条款。Capricorn 不代收第三方服务费用，也不保证第三方服务的可用性、价格或免费额度长期不变。

## 🏗️ 技术架构

```text
┌──────────────────────────────┐
│       Qt 6 / C++ 前端         │
│  界面 · 桌宠 · 本地数据 · 语音  │
└──────────────┬───────────────┘
               │ 本地 HTTP
┌──────────────▼───────────────┐
│           Go Core            │
│ 模型协议 · 人格会话 · 记忆管理  │
└──────────────┬───────────────┘
               │ HTTPS
┌──────────────▼───────────────┐
│      用户配置的模型服务        │
└──────────────────────────────┘
```

- **Qt 6 / C++**：桌面界面、桌宠动画、聊天、本地数据与语音录制
- **Go Core**：模型协议适配、人格约束、上下文和长期记忆管理
- **SQLite**：聊天记录及记忆持久化
- **Inno Setup**：生成 Windows 安装程序，仅用于构建

## 🗂️ 项目结构

```text
.
├─ frontend-qt/        # Qt/C++ 前端、桌宠与资源
├─ core-go/             # Go 模型与记忆核心
├─ shared/              # 内置人格与问题数据
├─ installer/           # Inno Setup 安装脚本
├─ scripts/             # 完整构建脚本
├─ BUILD_v1.0.0.cmd     # Windows 一键构建入口
└─ CMakeLists.txt       # CMake 入口
```

## 🔄 一次聊天是怎样完成的？

1. Qt 前端读取当前人格、用户记忆、关系记忆和近期聊天。
2. Go Core 创建人格会话，并根据模型协议整理请求。
3. Core 将请求发送到用户配置的模型服务。
4. 模型回复经过人格规则和身份边界处理后返回前端。
5. 聊天记录与记忆更新保存在本地，供下一次对话继续使用。

## 🧠 记忆设计原则

- 全局用户记忆与单个桌宠的关系记忆分开保存
- 用户明确表达优先于模型猜测
- 删除消息后会重建相关关系记忆
- 不把桌宠的人格设定误当成用户事实
- 不主动泄露人格文档、系统规则、API Key 或底层模型身份

## 🛠️ 从源码完整构建

### 环境要求

- Windows 10/11 x64
- Qt 6.8+，包含 Widgets、Network、Svg、Sql 及对应 MinGW/MSVC 工具链
- CMake 3.24+
- Go 1.23+
- Inno Setup 7 x64

### 一键构建

双击根目录文件：

```text
BUILD_v1.0.0.cmd
```

或使用 PowerShell：

```powershell
.\scripts\build-v1.0.0.ps1
```

需要指定 Qt 时：

```powershell
.\scripts\build-v1.0.0.ps1 -QtRoot "C:\Qt\6.11.1\mingw_64"
```

构建脚本会自动：

1. 编译 Go Core
2. 编译 Qt 前端
3. 部署 Qt 运行库和插件
4. 校验项目版本、资源路径和桌宠资源
5. 执行启动冒烟测试
6. 生成便携 ZIP
7. 生成安装程序
8. 输出两个发行物的 SHA-256

### 📦 构建产物

```text
Capricorn-v1.0.0-Windows-x64/
Capricorn-v1.0.0-Windows-x64.zip
Capricorn-v1.0.0-Setup-x64.exe
```

ZIP 与安装版来自同一个已校验的 staging 目录，避免“安装版少个 DLL，便携版少只宠物”这种薛定谔式发布。

## ✅ 调试与验证

完整构建脚本会检查：

- Qt、CMake、Go 和 Inno Setup 版本
- 项目版本及资源路径
- QRC 文件引用和外部桌宠资源数量
- 发布目录中的 DLL、插件、Go Core 和 50 张桌宠 SVG
- 打包后的 ZIP 内容
- 安装程序是否成功生成
- 发布程序能否通过启动冒烟测试

应用还提供启动冒烟测试和 UI 审计入口，便于在修改界面或启动流程后快速发现问题。

## 🧭 开发建议

- 修改人格或记忆逻辑后，优先检查跨人格数据是否串台
- 修改 Qt 资源后，确认路径保持 ASCII，避免 Windows 工具链编码问题
- 不要把 API Key、用户数据或本地发布产物提交到仓库
- 发行前同时验证 ZIP 和 Setup.exe，二者应来自同一份 staging 目录

## ⚠️ 当前边界

- 当前主要支持 Windows x64
- AI 对话需要可用的第三方模型 API 和网络连接
- 实时语音识别需要百度语音服务凭据
- 仓库不包含模型额度、API Key 或开发者代码签名证书——公开这些东西，通常比 Bug 更快登上热搜
